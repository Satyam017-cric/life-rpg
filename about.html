SYSTEM OVERVIEW

How Life RPG works.

A real-world productivity system wrapped in an RPG progression loop.

🔐

Secure accounts

Each character gets isolated server-side records, password hashing and session authentication.

🗄

Real persistence

SQLite stores users, quests, attributes, inventory and activity history so a refresh does not erase progress.

📈

Non-linear progression

Higher levels require increasingly more XP, so progression slows naturally as the character grows.

♿

Accessible UI

Semantic landmarks, labels, keyboard-friendly controls, visible focus and responsive layouts are built in.
